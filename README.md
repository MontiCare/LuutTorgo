# Луут Торго

Монгол үндэсний хувцасны урлангийн нүүр хуудас болон /admin удирдлага. Нийтлэл, зураг, хүсэлт, нэвтрэх сессийг хувийн Vercel Blob санд хадгална. Ирсэн хүсэлтийг Улаанбаатарын огноогоор шүүнэ.

Vercel дээр Node.js 24 болон төслийн vercel.json тохиргоог ашиглана. Хувийн Blob санг холбож BLOB_READ_WRITE_TOKEN тохируулна. CMS_SECRET нь санамсаргүй 32 байт нууц утга, CMS_PASSWORD_HASH нь salt:hex хэлбэрийн scrypt шалгагч (64 байт) байна. Эдгээрийг зөвхөн серверийн production орчинд тохируулна. Preview туршилтад тусдаа хувийн сан болон тусдаа нууц утгууд хэрэглэнэ.

Нүүр хуудсыг бүтээхдээ npm install, npm run build ажиллуулна. Vercel нь api/cms.js функцийг статик файлуудтай хамт байршуулна. Анхны долоон бүтээгдэхүүн, гурван постерын мэдээлэл lib/seed.json файлд байна. Анхны засвар хүртэл эдгээрийг шууд уншина.
